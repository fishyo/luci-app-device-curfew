luci-app-device-curfew 软件源

基于 firewall4 (nftables) 的 OpenWrt 局域网设备网络宵禁与家长管控 LuCI 应用官方源。

提示：本软件源始终保持为最新稳定版本覆盖策略。如需历史版本回滚，请前往 GitHub Releases 下载离线包。

1. OpenWrt 25.x 软件源 (apk)

apk v3 格式

导入签名公钥（安全校验非空）并添加软件源：

# 1. 导入源签名公钥（如源已签名）
mkdir -p /etc/apk/keys
wget -q -O /tmp/fishyo-device-curfew.pem https://fishyo.github.io/luci-app-device-curfew/apk/fishyo-device-curfew.pem 2>/dev/null || true
if [ -s /tmp/fishyo-device-curfew.pem ] && grep -q 'BEGIN PUBLIC KEY' /tmp/fishyo-device-curfew.pem 2>/dev/null; then
    mv /tmp/fishyo-device-curfew.pem /etc/apk/keys/fishyo-device-curfew.pem
else
    rm -f /tmp/fishyo-device-curfew.pem
fi

# 2. 添加软件源
echo "https://fishyo.github.io/luci-app-device-curfew/apk/packages.adb" > /etc/apk/repositories.d/device-curfew.list

# 3. 更新并安装
apk update
apk add luci-app-device-curfew

备用源直链 (Raw GitHub)：https://raw.githubusercontent.com/fishyo/luci-app-device-curfew/gh-pages/apk/packages.adb

2. OpenWrt 22.03 ~ 24.10 软件源 (opkg)

opkg / ipk 格式

在 /etc/opkg/customfeeds.conf 添加源：

# 1. 添加软件源
echo "src/gz fishyo_device_curfew https://fishyo.github.io/luci-app-device-curfew/opkg" >> /etc/opkg/customfeeds.conf

# 2. 更新并安装
opkg update
opkg install luci-app-device-curfew

3. 目录与构建产物

  • apk/packages.adb (APK v3 索引数据库)
  • apk/fishyo-device-curfew.pem (APK 签名公钥，如已签名)
  • opkg/Packages.gz (OPKG 索引)
  • GitHub 项目主页
